# Tokyo — framing (pilot)

Event: **Sep 9, 2026** (wave 1, APJ). Grounded in AI Tinkerers, Builders Weekend, Impact Tokyo, Flutter Hackathon, Mercari, and VIBE Coding event histories (2025–2026, JP+EN sources; Tokyo is bilingual — search both languages).

## Target neighborhoods (ranked)

1. **Shibuya (渋谷)** — safest bilingual bet: Builders Weekend 2026 (48h AI hackathon), ai& × Moonshot Tokyo Hackathon Night, Tokyo Tech Meetup. Dedicated event spaces like SAKURA DEEPTECH (cap 150, ¥200k start), Shibuya QWS.
2. **Nihonbashi / Kayabacho (Chūō)** — hosted Impact Tokyo Hackathon 2026 (Antler-led) at FinGATE KAYABA. Startup/VC dense.
3. **Roppongi (六本木)** — sponsor/enterprise tech events: Mercari Cursor meetup (thousands), VIBE CODING at Roppongi Hills · Hills Café/Space. Many small coworking rooms—filter for large event spaces.
4. **Akihabara / Odaiba (秋葉原 / お台場)** — platform hackathons (Flutter, 100-cap at docomo R&D OPEN LAB ODAIBA) and rentable 101–200-person conference rooms, but historically weaker bilingual meetup evidence.
## "Don't waste time"
- **Otemachi / Marunouchi** — finance district; no community hackathon evidence.
- **Coworking-only corporate rooms** (Roppongi) — many are 2–20 person meeting rooms; don't assume they scale to 200.
- **Café-only drop-ins (Akihabara)** — short-stay desks, not full-day 50-200 hackathon venues.

## Scope for this run
Full Tokyo = 4 neighborhoods × 2 types. First discovery fan-out: **Shibuya, Nihonbashi/Kayabacho, Roppongi** (3 coffee + 3 cowork/event cells). Akihabara/Odaiba is a follow-up once the top-three shapes are validated.
