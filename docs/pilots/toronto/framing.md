# Toronto — framing (dry-run)

Grounded in TechTO / AI Tinkerers / Elevate / TMLM event histories (2025–2026). Event: Sep 29, 2026.

## Target neighborhoods (ranked)
1. **King West / Liberty Village** — densest proven cluster: TechTO "Together Toronto" at Schwartz Reisman (College St), AI Tinkerers at Google King St W + Cohere John St, OneEleven etc. The "SoMa near 2nd St" analogue.
2. **Queen West** — Elevate satellite ecosystem, mid-size cafés with private rooms (Drake, Bovine), creative-corridor vibe match.
3. **Downtown Core / Financial District (College–Bay)** — MaRS / innovation campus, machine-learning meetups, fallback booking infrastructure.

## Explicitly wrong for this
- Yorkville (luxury-dining, <100 caps, no flex coworking)
- Distillery District proper (small exhibition spaces, not power/Wi-Fi hack venues)
- Port Lands / Enercare (too big / too impersonal)
